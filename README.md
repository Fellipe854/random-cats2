# Random Cats 🐱

Este projeto tem como objetivo exibir imagens aleatórias de gatos para os usuários.

A ideia principal é proporcionar uma experiência simples e divertida, onde o usuário pode gerar novas imagens de gatos a cada interação.

## Funcionalidades

- Exibir imagens aleatórias de gatos
- Atualizar imagem ao clicar em um botão

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
